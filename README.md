<h1 align="center">SV Academy · Claude Skills</h1>

<p align="center">The skills we teach, free, at <a href="https://loop.sv-academy.org/tutorials">loop.sv-academy.org</a>.</p>

Every lesson on Loop teaches one real Claude skill. This repo is the map: what each skill does, which lesson teaches it, which repo it lives in, and who deserves the credit.

**Transparency first.** We didn't invent most of these. Where we publish our own version, it is clearly marked as an SV Academy edition, keeps the original license, and credits the source. Where a license doesn't allow republishing, we wrote our own clean room implementation and say so. Every skill now ships as its own repo, so this page stays a map instead of a manual.
